Real-Estate AI Chat Demo — Quickstart (Windows-friendly)

1) Backend (port 3000)
- Open a new terminal in the repo root
- If PowerShell blocks npm.ps1, use npm.cmd explicitly

Commands:
  - cmd
    cd backend
    npm.cmd install --no-fund --no-audit
    node server.js

2) Frontend (port 3001)
- Open another terminal in the repo root
- The frontend proxies /api/* to the backend via next.config.js

Commands:
  - cmd
    cd frontend
    npm.cmd install --no-fund --no-audit
    npm.cmd run dev

Open in browser:
- http://localhost:3001
- Click Chat, try: 3 bed Clifton

Troubleshooting
- If PowerShell execution policy blocks npm: run cmd.exe or set policy
  PowerShell (optional):
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
- If API calls fail from the frontend, ensure backend is running on 3000
- If ports are busy, set PORT env or change dev ports accordingly
